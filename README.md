# 📈 Future Flare – Stock Forecasting

**Future Flare** is a lightweight stock forecasting web application designed to provide users with predictive insights into stock price movements. By leveraging recent historical stock data and powerful forecasting models, the app helps users visualize future price trends with ease.

---

## 🔮 Project Overview

Future Flare combines modern frontend development with predictive analytics and financial data APIs to build an intuitive forecasting experience. The system pulls recent stock data, stores it efficiently, analyzes patterns using machine learning, and displays results through a clean UI.

---

## 🧠 Features

- 🔄 **Historical Data Fetching** – Retrieves last 5 days of stock data using the **Yahoo Finance API**
- 💾 **Database Storage** – Stores and manages stock data using **SQLAlchemy** and relational databases
- 📊 **Forecasting Engine** – Uses the **Prophet** ML model to generate price predictions
- 🌐 **Web Interface** – Built with **HTML, CSS, and JavaScript** for simple user input and result visualization
- 📈 **Predictive Charts** – Displays forecasted stock prices and trends in a user-friendly format

---

## 🛠 Tech Stack

| Layer        | Technology                       |
|--------------|----------------------------------|
| Frontend     | HTML, CSS, JavaScript            |
| Backend      | Python, Flask (optional)         |
| Database     | SQLAlchemy + SQLite/PostgreSQL   |
| Data API     | Yahoo Finance (`yfinance`)       |
| Forecasting  | Prophet (by Facebook)            |

---

## ⚙️ How It Works

1. **User Input**: The user enters a stock symbol (e.g., `AAPL`, `GOOGL`)
2. **Data Collection**: The app fetches historical stock prices for the last 5 days via the Yahoo Finance API
3. **Data Storage**: Collected data is stored in a SQL database using SQLAlchemy
4. **Prediction**: The Prophet model processes the data and forecasts future prices
5. **Results Display**: The frontend displays the predicted trends in a clean, responsive chart
